# Perfil de José Juan Méndez Lara

## Descripción
Se desarrolló y personalizó la pantalla PerfilJoseJuan utilizando FlutterFlow.

Esta interfaz permite mostrar información personal y académica de uno de los integrantes del equipo.

## Información presentada
- Nombre: José Juan Méndez Lara.
- Carrera: Ingeniería en Desarrollo y Gestión de Software.
- Grado y grupo: 10.º B.
- Materia: Desarrollo Móvil Integral.
- Fotografía personal.

## Diseño
- Fondo: `#F5F7FA`.
- Fotografía circular de 120 × 120 píxeles.
- Nombre destacado en azul.
- Información académica centrada.
- Separación entre elementos mediante Items Spacing de 12 píxeles.
- Botón Regresar.

## Funcionamiento
Se configuró el botón Regresar mediante el evento `On Tap` y la acción `Navigate Back`, para volver a la pantalla anterior.

## Estado
Diseño individual terminado y navegación de regreso configurada.
