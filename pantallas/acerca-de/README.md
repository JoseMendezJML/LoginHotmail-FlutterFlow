# Pantalla Acerca de nosotros

## Descripción
Se desarrolló la pantalla AcercaDePage para presentar a los cuatro integrantes del equipo de desarrollo.

Cada integrante cuenta con un botón que permite acceder a su perfil individual.

## Diseño
- Fondo de pantalla: `#F5F7FA`.
- Título: Acerca de nosotros.
- Subtítulo: Conoce a nuestro equipo de desarrollo.
- Cuatro botones con fondo blanco, texto azul y bordes redondeados.
- Distribución vertical de los integrantes.

## Funcionamiento
Cada botón utiliza el evento `On Tap` y la acción `Navigate To` para abrir el perfil correspondiente.

| Botón | Página de destino |
|---|---|
| José Juan | PerfilJoseJuan |
| Efrén | PerfilEfren |
| Valeria | PerfilValeria |
| Yulissa | PerfilYulissa |

La navegación permite regresar desde cada perfil mediante la acción `Navigate Back`.
